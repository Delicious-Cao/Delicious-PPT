# Delicious-PPT

可配置的 PPT 制作与改稿 Skill，适用于课堂授课、工作汇报、项目提案、学术答辩、培训分享与阅读型演示文稿。**先了解用途与偏好，再制作；时长、内容密度、视觉风格和动画都由本次需求决定。**

| 版本 | Skill 文件 | 配图能力 |
| --- | --- | --- |
| ChatGPT | [delicious-ppt-chatgpt](skills/delicious-ppt-chatgpt/SKILL.md) | 可选生成图片、网络搜图、混合配图、仅用附件或不用照片 |
| DeepSeek | [delicious-ppt-deepseek](skills/delicious-ppt-deepseek/SKILL.md) | 不调用图像生成；需要外部配图时自行联网搜索、核验并嵌入 |

两个版本使用相同的需求询问方式与质量标准。DeepSeek 版按不使用图像生成能力的工作方式设计，也可选择只用用户素材、可编辑图表或纯文字排版。

## 默认字体与背景

| 项目 | 当前排版基准 |
| --- | --- |
| 中文标题 | 小标宋 |
| 中文正文及说明 | 仿宋，明确不加粗 |
| 数字、拉丁字母与英文 | Times New Roman（新罗马体），包括页码、图表及表格中的文字 |
| 图片背景 | 融入整页，与文字重合的区域局部淡化，文字保持清晰不透明 |
| 制作过程标签 | 清理页面及演讲者备注中自动添加的“AI生成场景示意”“AI配图”等字样 |

上述基准同时适用于两个版本，无需在每次制作前重复询问。使用者明确指定其他字体、模板或版式时采用其选择；字体缺失时说明并询问替代，不静默换字体。本仓库不捆绑字体文件。

## 先问哪些问题

先从消息、附件与已有对话中提取已知要求，**只问会影响结果的缺失信息**。每轮优先问 1–3 个相关问题，提供少量易选的建议，也接受自定义答案。

| 可选项 | 根据本次任务确认的内容 |
| --- | --- |
| 使用场景 | 用于授课、汇报、答辩、提案还是分享？面向谁，希望对方理解或决定什么？ |
| 演示方式与时长 | 现场讲述、自动播放还是独立阅读？讲多久，是否包括问答和互动？阅读型文件可以不设时长。 |
| 内容详略 | 精简要点、均衡解释还是详细可读？需要哪些关键内容，有没有页数限制？ |
| 视觉与配图 | 正式、简洁、活泼或其他风格？是否有模板、品牌色？需要何种来源和密度的图片？ |
| 动画与放映 | 不用动画、轻量动画还是逐步揭示？手动还是自动翻页？使用什么软件或导出格式？ |
| 资料与交付 | 使用什么语言、允许哪些资料来源？需要 PPTX、PDF、备注或讲稿？保存到哪里？ |

不要求每次填完所有项目。已经明确的内容不重复询问，字号、边距等常规实现由助手判断。关键信息未答时先等待回答，同时可整理已有资料；用户明确表示“你决定”时给出合理方案并继续，无需再次审批。

**38–40 分钟、PPT 展示约 80%、积极风格、每页配图、动画与保存桌面，均不再是通用硬性要求。** 原始偏好保留为可主动选用的“课堂评审预设”，详见各版本的 `references/requirements-intake.md`。本仓库最初对话中的偏好不会自动套用到后续所有使用者。

## 持续保留的质量标准

- 逻辑连贯、信息可读、符合受众和展示条件，不靠缩小文字硬塞内容。
- 按主题选择可信来源，核验事实、日期、数据口径与图片使用条件；遵守“仅用附件”等资料边界。
- 现场讲述版按已确认的时长安排节奏；阅读版优先保证独立可理解，不强加演讲时长。
- 图片如被选用，应实际嵌入；动画如被选用，应实际实现。允许纯色背景、纯文字页、图表页及完全静态的成品。
- 默认制作可编辑 PPTX，按所选输出方式验收；不声称完成了未实际执行的保存、排练或动态检查。

## 使用方法

### 支持 Skill 目录的工具

下载或克隆仓库，将选定的整个 Skill 文件夹放入宿主支持的技能目录，保留 `SKILL.md` 与 `references/` 的相对位置。例如，Codex 默认个人技能目录为 `~/.codex/skills/`；ChatGPT 版另附兼容宿主可识别的 `agents/openai.yaml`。

### 普通对话

上传所选版本的 `SKILL.md`、该目录的参考文件，以及本次需要使用的资料。只接受文本的界面可以粘贴对应文件内容。宿主需提供本次任务所需的文档读取、检索、制图与导出工具，Skill 本身不会新增这些能力。

通用提示：

```text
请使用 Delicious-PPT 的 ChatGPT 版帮我制作 PPT。
先读取我提供的资料，向我确认尚未说明的用途、受众、时长、
内容详略、风格、配图与动画偏好；已明确的要求不用重复问。
```

也可以直接提供完整需求，减少询问：

```text
使用 Delicious-PPT 的 DeepSeek 版，把这份材料做成 10 分钟的项目汇报，
面向管理层，以结论和决策建议为主，风格正式简洁。
联网核验必要数据，少量网络配图，不用动画，输出 PPTX 和 PDF，
保存到我指定的文件夹。不需要讲稿，其余细节你决定。
```

默认只选一个版本，避免同时启用不同图片策略。
