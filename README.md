# Delicious-PPT

面向课堂授课、教学展示与听课评审的中文 PPT 制作 Skill。将原始文档转化为逻辑连贯、积极舒展、适合现场投影的演示文稿，默认授课总时长 **38–40 分钟**。

提供两个可独立使用的版本：

| 版本 | Skill 文件 | 图片与艺术字策略 |
| --- | --- | --- |
| ChatGPT | [delicious-ppt-chatgpt](skills/delicious-ppt-chatgpt/SKILL.md) | 按页生成主题图片与必要的艺术字，也可检索合适的网络图片 |
| DeepSeek | [delicious-ppt-deepseek](skills/delicious-ppt-deepseek/SKILL.md) | 不调用图像生成；主动联网检索、核验、下载并嵌入图片，艺术字用可编辑文字效果实现 |

两个版本的教学、内容、时长、视觉、动画和交付标准一致，仅视觉素材的获取方式不同。DeepSeek 版按不使用图像生成能力的工作方式设计。

## 核心约定

- 先读用户提供的文档，保留教学目标、重点、案例和评审关注点；缺少文档或影响内容正确性的关键信息时，先集中提问。
- 面向听课评审员组织信息。PPT 展示约 **80% 的核心讲述内容**，约 **20% 留作口头补充**。这是信息覆盖的近似比例，不是字数、页面面积或时间的机械配额；不另写发言稿。
- 全程按 **38–40 分钟**安排，包含开场、讲解、互动、动画、切换和结尾；通过逐页时长计划与排练核验。
- 风格积极、明亮、舒展。先评估设计依据的来源与适用范围，再安排层级、留白、对比、对齐和视觉平衡。
- 事实优先核对政府、主管部门、原始发布机构，以及新华社、人民日报、中央广播电视总台等中央媒体；保留可追溯的具体出处。
- 每个文字块明确采用整组出现、逐项出现或静态展示；按场景设置真实的文字动画与翻页过渡。
- 每页配置与主题匹配的背景或视觉主体，结合半幅、全幅、完整场景与左右图文布局，确保文字清晰。
- 支持生成文件时交付可编辑 `.pptx`，渲染逐页检查，并保存至实际桌面目录；无法访问桌面时提供下载入口并如实说明。

## 使用方法

### 支持 Skill 目录的助手或工具

下载或克隆本仓库，将选定的整个 Skill 文件夹放入宿主工具支持的技能目录。保留 `SKILL.md` 与 `references/` 的相对位置。

例如，Codex 的默认个人技能目录为 `~/.codex/skills/`，可以放入 `skills/delicious-ppt-chatgpt/` 整个文件夹。ChatGPT 版附有可供兼容宿主识别的 `agents/openai.yaml`。

### 普通对话方式

向助手上传选定版本的 `SKILL.md`、该文件夹中的参考文件和授课原始文档；如果界面只接受粘贴文本，先粘贴 Skill 正文，再补充它要求读取的参考内容。要求助手将这些文件作为本次制作规范执行。

两版均需要宿主提供文档读取、联网检索与 PPTX 制作能力；ChatGPT 版的图片生成还需要可用的图像生成工具。Skill 本身不会新增这些工具。

推荐提示：

```text
请使用 Delicious-PPT 的 ChatGPT 版，阅读我上传的文档，
制作一份面向课堂听课评审的 38–40 分钟 PPT。
按 PPT 展示约 80%、口头补充约 20% 的比例组织内容，
不写发言稿。存在关键缺失信息时先向我提问。
```

使用 DeepSeek 时，将上面第一行替换为“请使用 Delicious-PPT 的 DeepSeek 版”，并提供该版本的文件。默认只选用一个版本，避免两种图片策略同时生效。

## 文件结构

```text
skills/
├── delicious-ppt-chatgpt/
│   ├── SKILL.md
│   ├── agents/openai.yaml
│   └── references/
│       ├── visual-design.md
│       └── delivery-checklist.md
└── delicious-ppt-deepseek/
    ├── SKILL.md
    └── references/
        ├── visual-design.md
        └── delivery-checklist.md
```

每个版本可以单独复制使用。两份视觉参考与验收清单保持一致，便于在不依赖仓库其他目录的情况下使用。
