# 需求询问与场景配置

首次接到制作任务时，或旧任务的用途发生明显变化时读取。充分了解使用者的真实目标、限制与偏好，以约99%的需求理解为开工目标；问题可以详细，也可以多轮追问。按已有信息适配访谈，不机械要求每位用户重复填写全部项目。

## 询问节奏

1. 先完整阅读消息、已有对话及可用附件，建立需求记录。每项标为“已明确”“用户已授权助手决定”“不适用（注明依据）”或“待确认”。仅在用户指向前次方案时沿用其参数，不把其他任务的选择变成永久默认。
2. 第一阶段了解任务背景、受众和成功标准；第二阶段深入内容范围、时长、详略、视觉、放映和交付；第三阶段核对例子、优先级、冲突及遗漏。阶段可按回答灵活合并，不设置固定问句长度、固定轮数或机械的问题数量。
3. 问题写到足以准确理解的程度。可解释为什么问、不同答案会怎样改变成品，并给出选项、具体例子或反例；允许自由回答和补充。宿主限制一次问题数量时拆分轮次，不能因工具限制跳过必要需求。
4. 对“正式一点”“内容丰富”“不要太花”等含糊回答继续追问可执行的含义，例如偏好的参考、文字密度、色彩、重点和不喜欢的处理。主动检查答案是否矛盾，确认必须保留项和冲突时的优先级。
5. 每轮吸收已回答内容并更新需求记录，再询问仍未明确且影响结果的部分。关键需求必须充分了解，不为赶进度缩短访谈；也不重复追问已清楚的内容，或为声称达到99%而追问无关细节。
6. “你决定”“按推荐来”只把对应项目记为明确委托，并说明采用方案；不能把局部委托视为其余未知项的答案。用户只答了部分问题时保留回答并继续核实关键缺项。
7. 需求未明确或仍在等待必要回答期间，只做现有资料阅读、整理和工具核实，不开始正式内容编写、布局、批量生成或搜集背景、动画实现及 PPTX 制作。等待时间不是用户确认。
8. 满足下方开工门槛后提供完整《制作需求确认单》，让用户纠正理解并确认开工。若用户已对同一完整方案明确确认并授权，无需重复确认。开工后出现新增关键要求时更新受影响项并确认，不无故重问全部问题。

## 开工门槛：约99%理解

“99%”用以下条件落实，不以无依据的主观百分比替代检查：

- 任务背景、受众、目标和成品成功标准已清楚，知道哪些内容最重要、使用者希望成品发挥什么作用。
- 所有适用的关键项已回答，或使用者已明确授权助手决定；不适用项有理由，待确认项仅可剩余不会改变方向的低影响实现细节。
- 必需附件及其使用边界明确，时长、页数、内容、风格或模板之间的矛盾已解决；没有会导致大幅返工的未知项。
- 生成或搜图、字体、动画、放映软件与交付位置等实施条件已核实，能力缺项已向用户说清并得到明确处理安排。
- 《制作需求确认单》准确复述了使用者需求，必要纠正已吸收，并已获得针对该方案的开工授权。不能先做成品再让使用者确认需求。

## 制作需求确认单

用清楚的段落或表格呈现，不要求冗长但也不限制为一小段：

1. 任务背景、使用场景、目标受众、希望实现的结果与评判标准。
2. 主题、必须保留和不能改动的内容、可删减范围、重点难点与结构方向。
3. 总时长及是否包含互动和问答，页数限制、内容详略和讲述配合方式。
4. 语言、语气、参考风格、品牌或模板、背景主题与构图；重申本版强制背景、字体和逐段动画要求。
5. 事实来源范围、引用方式、额外素材与附件的使用边界。
6. 放映软件、手动或自动推进、交付文件与保存位置、截止时间，以及用户要求的验收重点。
7. 已明确委托助手决定的项目、准备采用的方案、剩余低影响细节及其处理方式。

向用户明确说明这是开工前的需求复述，并请其纠正或确认。没有新增未确认决定、且用户已经对相同完整配置授权开工时，说明记录后继续，无须重复索取同一授权。

本 Skill 强制要求：每页图片背景（ChatGPT 实际生成，DeepSeek 实际联网搜图）、逐段安排整组或逐项出现及有场景理由的静态例外、小标宋标题、仿宋正文不加粗、数字字母 Times New Roman、背景整页融合与文字区局部淡化，以及清理制作过程标签。不得因为‘通用性’或‘你决定’而省略；只有使用者后续明确变更对应要求才调整。字体或工具缺失时只就缺项提问，不能静默降级。

## 可以询问的参数

| 参数 | 提问或选项示例 | 执行要点 |
| --- | --- | --- |
| 用途、受众与目标 | “面向学生授课、向管理层汇报，还是学术答辩？希望听众最终理解或决定什么？” | 根据受众知识水平组织信息；有明确评价标准时读取 |
| 使用方式 | “现场配合讲解、自动循环播放，还是发给别人独立阅读？” | 阅读版不强制时长；自动播放需考虑停留与循环条件 |
| 时长及口径 | “希望讲多久？其中是否包含问答和互动？是硬性上限还是大致目标？” | 接受具体分钟、区间或不限；没有获知时长前不默认 40 分钟 |
| 内容范围与页数 | “哪些内容必须保留？有页数限制吗？” | 已给资料可先总结要点；不要求所有任务必须先上传文档 |
| 详略与讲述配合 | “偏精简要点、均衡解释，还是详细可读、便于照着讲？” | 比例可选，不要求用户给数字；指定八二开时明确哪一方占八成 |
| 风格与模板 | “想要正式简洁、温暖明亮还是活泼有冲击力？有品牌色或模板吗？” | 调整色调和构图；模板与强制字体或背景要求冲突时先说明具体冲突 |
| 背景构图 | “偏完整场景、左右留白，还是低干扰背景？色调有什么偏好？” | ChatGPT 必须生成、DeepSeek 必须联网搜图；不提供无图片背景、仅用附件背景或互换获取方式的选项 |
| 动画编排与兼容性 | “文字以整组出现为主，还是逐项揭示？手动还是自动推进？用什么放映软件？” | 每段都有出现安排；静态例外必须匹配具体场景，PDF 静态导出不能冒充动态成品 |
| 内容边界与出处 | “事实内容仅使用现有材料，还是允许联网补充？是否限定来源或引用格式？” | 内容检索与强制背景获取分开处理；明确禁止背景获取的要求须先澄清冲突 |
| 语言与交付 | “输出语言、格式和保存位置有什么要求？需要备注或另附讲稿吗？” | 优先从任务中提取；默认不另写讲稿，只有被要求才添加 |
| 成功标准与优先级 | “您最希望听众记住什么、理解什么或做出什么决定？如果时间、页数和内容完整性冲突，哪项优先？有哪些一定不能出现的问题？” | 把抽象的“做好看、做专业”转成可执行目标，确认关键取舍 |
| 材料保留与修改范围 | “原材料哪些必须原样保留，哪些可以改写、补充或删减？现有版本最需要解决什么问题？” | 区分新建、局部改稿和整体重做，避免擅自扩大范围 |
| 参考与排斥项 | “有喜欢或不喜欢的参考吗？请说明更在意其配色、图片气质、文字密度、版式还是讲述节奏。” | 有参考时先解释自己的理解，再让用户纠正；没有参考也可通过具体描述确认 |
| 技术与时间安排 | “计划在 PowerPoint、WPS 或其他软件中放映？投影还是电脑阅读、是否自动播放、何时需要交付？” | 用户提供使用条件，工具能力和字体由助手实际检查；技术未知项不能靠猜测填上 |

## 详细提问示例

下面展示问题需要达到的理解深度，可根据上下文拆分或合并，不要求照抄：

- “这份 PPT 会在什么场合使用，现场主要有哪些人，他们对主题的熟悉程度怎样？您希望他们在结束时记住哪些结论、认可什么观点，或者做出什么决定？这会影响我采用教学式展开、结论先行的汇报，还是以证据支撑的提案结构。”
- “您希望总时长是多少，属于必须遵守的上限还是大致范围？这个时间里是否已经包含开场、互动等待、视频和问答？如果保留全部材料会超时，您希望优先保证内容完整、讲解充分还是时长上限？请指出必须保留的部分。”
- “您说希望‘正式但有活力’，更接近稳重的机构汇报，还是色彩更鲜明的培训展示？可以描述喜欢或不喜欢的参考，也可以指出您更看重图片气质、留白、文字密度还是讲述节奏。我会在既定字体、整页图片背景与淡化要求下实现这些偏好。”

所选版本必须使用的图像生成或网络搜图能力由实际工具环境核实。能力缺失时说明尚未满足的要求；确认前仅整理理解资料，完成需求确认与开工授权后才继续不受影响的制作工作。不能自行改成纯色背景或把搜图工作交给使用者后声称已完成。

## 场景建议

这些是组织内容的起点，不是强制模板或固定页数。

| 场景 | 组织重点 | 需要特别确认 |
| --- | --- | --- |
| 课堂、培训 | 目标、概念、案例、练习、回顾 | 学员基础、互动方式、总时长是否含活动 |
| 工作汇报 | 结论、进展、数据、问题、下一步 | 管理层关心的问题、汇报时段、数据范围 |
| 项目提案、路演 | 问题、方案、价值、证据、所需决策 | 受众决策目标、展示时间、商业或品牌约束 |
| 学术答辩 | 研究问题、方法、证据、贡献、局限 | 专业背景、学校模板、答辩与问答时间 |
| 独立阅读材料 | 解释完整、图表可理解、结论可追溯 | 阅读场景、信息密度与导出格式；可不设演示时长 |
| 现有 PPT 改稿 | 保留已认可的信息与结构，修复指定问题 | 修改范围与需保留项；不把局部修正变成全套重做 |

## 可选：原始课堂评审预设

仅在用户明确选用“课堂评审预设”、要求“沿用最初课堂方案”，或确认以下参数时启用。仅提到“课堂”不足以自动启用整套预设。用途、时长、详略和保存位置等可再调整；本 Skill 的强制制作要求仍执行。

- 面向课堂听课评审，目标是评审员从页面看懂主线、讲者有内容可读。
- 总时长 38–40 分钟，包含讲解、互动、动画和切换；可以 39 分钟为规划中点。
- PPT 展示约 80% 的核心讲述内容，约 20% 留作口头补充；比例指信息覆盖，不是页面填充率。
- 风格积极、舒展；每页配置主题背景或视觉主体，结合半幅、全幅、完整场景与左右图文布局。
- 字体采用小标宋标题、不加粗的仿宋正文和 Times New Roman 数字字母；背景图融入整页，文字覆盖区域局部淡化。
- 根据教学节奏安排整组出现、逐项揭示或静态文字，并配置轻量翻页过渡。
- 政策与公共议题优先核对官方、主管部门和中央媒体出处；不额外撰写发言稿。
- 保存到实际桌面；无法访问桌面时提供下载文件并说明。图片获取方式仍遵循所选版本。

## 配置记录示例

可简记在工作上下文中，不要求另交表格文件：

```text
用途：季度项目汇报；受众：管理层；目标：决定下阶段资源投入
使用方式：现场讲解；时长：10 分钟，不含 5 分钟问答；页数：不限
内容：结论优先、精简要点；语言：中文；风格：正式简洁
背景：每页按所选版本生成或联网搜图，整页融合、文字区淡化
动画：逐段整组或逐项淡入，静态例外按场景记录；翻页：手动短淡化
字体：小标宋标题、仿宋正文不加粗、数字字母 Times New Roman
资料：允许联网核验，内部数据只用附件；交付：PPTX + PDF
备注/讲稿：不需要；位置：用户指定文件夹
```
