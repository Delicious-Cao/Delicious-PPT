# 原始材料：城市自然观察

这是一份原创的观察练习说明，用来展示使用网络背景图片制作演示文稿。它不包含真实调查结果，也不根据照片推断植物物种。

在城市公园或身边开放的绿地开展一次简单观察。可以先选择一片叶子，描述它的整体轮廓、叶缘以及主脉和细脉的走向，再比较不同光线下的样子。

户外练习建议安排10分钟：前2分钟选定观察点并记录时间和位置，第2至7分钟观察、描写和拍照，最后3分钟整理一项有趣发现，选一张照片用于分享。

观察时沿开放步道行走，让植物保持原来的样子。记录先写看见的细节，再写自己的推测；分享时说明时间、位置和具体发现。

用于说明活动方法的简短讲解约5分钟，户外练习10分钟另计。讲解时间为示例规划，未作为完整授课排练记录。
