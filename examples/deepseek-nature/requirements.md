# 样例需求设定：城市自然观察

## 授权与范围

使用者已授权维护者随机选择样张。本方案由维护者在授权范围内拟定，用于公开展示；不是实际客户访谈，也没有捏造使用者的逐项回答。

| 项目 | 已确定的示例配置 |
| --- | --- |
| 目标 | 说明一种容易参与的城市自然观察与分享练习 |
| 受众 | 普通学习者与活动参与者，无需植物分类知识 |
| 内容 | 叶片观察、10分钟户外安排、记录与分享，不推断物种或添加调查数据 |
| 规模 | 4 页，讲解规划约5分钟，户外练习10分钟另计 |
| 风格 | 清新自然、浅绿色、植物照片与整页背景融合 |
| 背景 | 按 DeepSeek 版策略自行联网搜索 4 张图片，核对 CC0 许可后嵌入 |
| 字体 | 小标宋标题、仿宋正文不加粗、数字字母 Times New Roman |
| 动画 | 标题随页淡入，正文点击逐项淡入，表格整组出现，页码静态定位，翻页淡化 |
| 输出 | 可编辑 PPTX、静态 PDF、逐页 PNG、原生动画缩时 MP4 |
| 时间分配 | 封面45秒、观察方法90秒、活动安排90秒、总结75秒 |
| 资料边界 | 文字来自 input.md；网络图片有真实来源，不声称是本次活动的现场照片 |

本示例由维护环境按搜图策略制作，未在 DeepSeek 官方客户端独立运行。随机主题、配色与页面安排属于本次委托范围；真实使用者任务仍须充分访谈与确认。
