# 示例构建与验证说明

日期：2026-10-21。参考环境：Windows，Microsoft PowerPoint 16.0，Build 20430。

两组样例使用本机 PowerPoint 原生对象制作，之后重新打开最终 PPTX 检查；没有使用整页截图替代可编辑幻灯片。

| 项目 | 校园阅读空间 | 城市自然观察 |
| --- | --- | --- |
| 页面数 | 4 | 4 |
| 每页嵌入图片背景 | 1 张，对应实际生成素材 | 1 张，对应已核验网络素材 |
| 原生可编辑表格 | 1 个 | 1 个 |
| 文字动画效果 | 14 个 | 14 个 |
| 翻页 | 各页均为淡化 | 各页均为淡化 |
| PPTX 推进方式 | 正文点击推进 | 正文点击推进 |
| 原生预览视频 | 1280×720，约26.08秒 | 1280×720，约26.08秒 |
| 正文加粗检查 | 未发现加粗 | 未发现加粗 |
| 数字字母检查 | 所检查的可编辑数字字母均为 Times New Roman | 所检查的可编辑数字字母均为 Times New Roman |

标题使用实际安装的方正小标宋简体，中文正文使用仿宋。字体在 PPTX 中声明，并在本机原生渲染中检查；未将字体文件加入仓库。

检查包含：PPTX 可重新打开、每页图片嵌入、动画及过渡结构、字体声明、数字字符字体、正文非加粗、文本框高度、原生表格、静态逐页预览及动画视频代表帧。页面定位用的页码静态显示，正文和标题按设定出现，表格整组出现。

两个动画视频由 PowerPoint 对相同页面和效果原生导出。预览时将触发改为自动、每页约6秒，未将这些缩时参数写回供下载的手动 PPTX。

原始材料、样例需求与素材来源都位于对应目录。机器可读的参考结果见 [verification.json](verification.json)。
