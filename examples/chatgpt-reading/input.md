# 原始材料：校园阅读空间

这是一份原创的试点提案材料，用来展示从简要材料组织成演示文稿的过程。它不描述已实施的学校项目，也不包含调查统计数据。

希望在校园里安排一个方便短暂停留的阅读角。可结合木质书架、简洁座位、自然光与少量绿植，让课间阅读成为一种容易参与的选择。

主要考虑三个使用情境：短时间翻阅、两三人的安静交流，以及独处阅读。空间布置应兼顾行走动线、取书和归还，不占用通道。

建议先试运行一周。第1天完成布置，确认座位与动线。第2至4天开放并观察使用和归还情况。第5天收集意见，整理下一轮调整。此安排仅为提议，可根据场地和课间时间修改。

希望收集的反馈包括：哪些时段有人使用、书是否归位、使用者最想保留和最想改变的内容。优先处理影响使用的问题，再考虑扩大空间或增加书目。
