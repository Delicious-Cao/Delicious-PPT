# 样例需求设定：校园阅读空间

## 授权与范围

使用者已授权维护者随机选择样张。本方案由维护者在授权范围内拟定，用于公开展示；不是实际客户访谈，也没有捏造使用者的逐项回答。

| 项目 | 已确定的示例配置 |
| --- | --- |
| 目标 | 介绍一个可讨论、可试运行的校园阅读角方案 |
| 受众 | 对阅读空间建设感兴趣的教师或学校活动组织者 |
| 内容 | 使用情境、一周计划、反馈与改进，不增加未经核实的统计数据 |
| 规模 | 4 页，总讲述规划约 5 分钟，未进行完整授课排练 |
| 风格 | 温暖明亮、木色与浅绿色、整页背景融入 |
| 背景 | 按 ChatGPT 版策略实际生成 4 张主题图片 |
| 字体 | 小标宋标题、仿宋正文不加粗、数字字母 Times New Roman |
| 动画 | 标题随页淡入，正文点击逐项淡入，表格整组出现，页码静态定位，翻页淡化 |
| 输出 | 可编辑 PPTX、静态 PDF、逐页 PNG、原生动画缩时 MP4 |
| 时间分配 | 封面45秒、使用情境90秒、安排90秒、总结与讨论75秒 |
| 资料边界 | 文字来自 input.md；画面是设计背景，不作为学校实景或项目结果证据 |

随机主题、配色、具体文案和页面安排属于本次明确委托维护者决定的范围。真实使用者的任务仍需按 Skill 访谈并确认其具体需求。
